# Routing mark — app v3 and tray v4

Two opposing geometric hooks form a diagonal routing passage. The app uses a white mark on ultramarine; the menu bar uses the same silhouette in black on transparency.

Generated with the built-in imagegen tool. Original versions are retained. macOS packaging uses `llm-gateway-icon-v3.png` for ICNS and `llm-gateway-tray-v4.png` for the 36 × 36 pixel, 144 DPI tray resource (18 logical points).

## App generation prompt

Use case: logo-brand.
Create ONE production macOS application icon for LLM Gateway. Redesign from scratch with a sharply modern, highly distinctive identity. Main concept: a compact abstract routing monogram made from exactly TWO bold opposing angular hooks. The upper-left hook and lower-right hook interlock optically without touching; their negative space creates a strong diagonal passage from lower-left to upper-right. Each hook is an angular bent band, like a squared-off bracket with a 45-degree cut terminal. Think rigorous contemporary Swiss geometric identity, precision, movement, infrastructural software. NOT an arch, doorway, letter A, house, headphones, infinity loop, chain link, sparkle, chevrons, or generic AI brain. The two shapes should be simple enough to redraw from memory and recognizable in solid monochrome at 18px. Keep broad negative-space separation, about half a band-width. Slightly softened corners, strong silhouette, optical balance.
Icon tile: rich electric ultramarine blue, almost flat with only an extremely subtle blue tonal shift, smoothly rounded-square macOS tile. Mark: both hooks pure porcelain white, flat. No other colors. Mark occupies 58% of the full canvas, centered. Tile occupies 88% of the canvas. Outside tile is fully transparent, with pristine smooth antialiased edges and absolutely NO stray pixels. Orthographic front view. Square image 1024x1024.
Strict constraints: no text or labels, no presentation layout, only one icon, no 3D extrusion, no metallic effects, no bevels, no drop shadow, no glass effects, no texture, no thin lines, no decorative dots, no glow. Sophisticated and bold, clean vector-like execution.
